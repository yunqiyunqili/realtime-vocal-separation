Low-latency singing-voice separation

A causal model that pulls the lead vocals out of a full music mix in real time, block by block, using only past audio plus 11.6 ms of lookahead. Below are 15-second excerpts from unseen songs.

  • Causal Conv-TasNetstereo, 44.1 kHz, ~6.0 M parameters
  • 11.6 msalgorithmic latency
  • RTF 0.44single CPU thread, 512-sample blocks
  • MUSDB18-HQ test50 songs, never used for training or model selection

Excerpts are not cherry-picked: songs were chosen by their per-song vocal uSDR on the test set — one near the 80th percentile, two near the median, one near the 20th percentile. Each excerpt is the 15 s with the strongest vocals, away from the start and end of the song. The model is run in streaming mode from the beginning of the song, exactly as in evaluation. All five versions of a song share one gain (peak −1 dBFS), so relative loudness is preserved. The spectral baseline is a separately trained causal STFT-mask model with the same 11.6 ms latency.
